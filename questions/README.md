# Question sets

Two sets, both disclosed as such, both hashed in the pre-registered protocol (`filing-ladder questions`).

## (i) `vals-finance-agent-public-50.csv`

The 50 public questions of the **Vals AI Finance Agent Benchmark** (arXiv:2508.00828), vendored
verbatim from [vals-ai/finance-agent](https://github.com/vals-ai/finance-agent) (`data/public.csv`):
expert-authored, peer-reviewed gold answers and rubrics, nine task categories, recent filings.
License **CC BY 4.0** (the questions and gold); the harness they ship is MIT. Do not edit this file.

These were written for document agents — they are stacked *toward* the document rungs — and each
one needs a filing resolved before the in-context rungs can run. That resolution lives in
`vals-filing-resolution.jsonl` (one line per question: `{"id": "vals-01", "filing": {"cik": …,
"accession": …, "ticker": …, "fiscal_year": …}, "notes": "…"}`), never inside the CSV. Questions
whose filings fall outside the corpus are dropped and listed in the protocol.

## (ii) `templates/*.jsonl`

FinanceBench-shaped questions re-instantiated on current filings, one JSON object per line
(`filing_ladder.questions.Question`), across the five strata:

| stratum | shape |
|---|---|
| `lookup` | one reported value, unambiguous |
| `dimension` | the consolidated total where nearly every context is a segment breakdown |
| `period` | Q4 standalone from YTD; a non-calendar fiscal year; TTM |
| `identity` | a value tagged on a custom extension concept |
| `structure` | what sums to a subtotal; which statement a fact sits on; the label of a custom concept |

**Numeric gold is read from the document by a person and says so** (`gold_source:
"document-read"`); judgement gold is CPA-authored and marked (`"cpa"`). Gold never comes from a
graph. The FinanceBench originals are CC BY-NC 4.0 and are not reproduced; the *shapes* are reused
with attribution.
